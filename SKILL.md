# Warm Lead Parser

Парсер тёплых лидов из открытых источников: FL.ru, Kwork, Freelance.ru, Weblancer, Telegram-биржи и Авито. Каждый пост получает балл готовности платить 0–100, движок отсеивает вакансии-наёмку и резюме соискателей, а на выходе — короткий список: с кем связаться сегодня и почему, плюс экономика прогона (цена тёплого лида в ₽).

Второй слой — **проверка заказчика по открытым госреестрам**: кто стоит за объявлением, какая отрасль, жив ли бизнес, кто руководитель и с кем говорить. Без API-ключей и регистраций.

Один файл `warm_lead_parser.py`, стандартная библиотека Python 3.10+, без зависимостей и без логинов. 53 преднастроенные ниши в `niches-50.json`, своя добавляется в конфиг за минуту.

## When to Use

Используй этот скилл, когда нужно:

- **«найди лиды»** — собрать потенциальных клиентов из открытых лент бирж и Telegram-каналов.
- **«парсер лидов»** — запустить механизм скоринга готовности платить и получить приоритетный список.
- **«тёплые клиенты»** — отсеять холодный шум и оставить только тех, кто уже пишет «нужен бот», «срочно доделать», «внедрить ИИ», «нарисовать арт».
- **«кто это такой»** / **«проверь заказчика»** — по ИНН, названию или тексту объявления собрать карточку бизнеса: отрасль, размер, живость, руководитель, контакт.
- **«проверить, платёжеспособен ли»** — отсеять ликвидированные компании и однодневки до отклика.
- **Парсинг FL.ru / Kwork / Авито** — собрать заказы с конкретных площадок: FL.ru, Kwork, Weblancer, Freelance.ru, Kadrof, poisk-pro, searchengines.guru, illustrators.ru и Авито (стелс).
- **Экономика прогона** — посчитать цену тёплого лида в ₽ для конкретной ниши и решить, стоит ли прогон своих денег.
- **Рыночная разведка** — Авито даёт цены конкурентов и полку, а не только лиды.

## When NOT to Use (анти-триггеры)

- **Не использовать: холодный outreach** — скилл не собирает email-базы и не рассылает сообщения, он приоритезирует уже опубликованные открытые посты.
- **Не использовать: email-рассылки** — нет механизма массовой отправки; `SAFETY_RAILS.md` явно запрещает массовый сбор контактов и рассылки.
- **Не использовать: парсинг закрытых/приватных данных** — читаются только открытые публичные ленты, без логинов.
- **Не использовать: как CRM или трекер сделок** — это инструмент разведки и приоритезации, а не управления клиентами.
- **Не использовать как досье на человека** — обогащение берёт то, что государство публикует само: организацию, её руководителя как публичную должность, деловой контакт.

## Как запустить

```bash
python warm_lead_parser.py --list                # список 53 ниш
python warm_lead_parser.py                       # все ниши, ~35 секунд
python warm_lead_parser.py chatbots              # одна ниша, полный прогон
python warm_lead_parser.py ai-agents --enrich-top=3   # + карточки бизнеса по топ-3 лидам
python warm_lead_parser.py --full                # с Авито (стелс)
```

Обогащение отдельной командой — если есть только ИНН из переписки:

```bash
python integrations/enrich.py --inn 7707083893
python integrations/enrich.py --name "Мастер-Ювелир"
python integrations/enrich.py --text "Нужен бот, ИНН 7707083893, бюджет 50 тыс"
python integrations/enrich.py --selftest             # 10 проверок без сети
```

## Результат прогона

- Скоринг 0–100 по каждому посту: точность ниши, названные деньги, срочность, ТЗ, свежесть, штраф за старость.
- Приоритеты: 🔥 связаться сегодня → 🌤 мягкий заход → 📊 рыночные сигналы.
- Экономика: затраты времени, стоимость тёплого лида в ₽.
- Блок «🏢 Кто за объявлением» (при `--enrich`): юрлицо, ИНН/ОГРН, отрасль по ОКВЭД, категория МСП, регион, руководитель, живость бизнеса, контакт.

## Обогащение по госисточникам

Три открытых источника, ноль ключей и регистраций:

| Источник | Что даёт | Скорость |
|---|---|---|
| **ЕГРЮЛ** (`egrul.nalog.ru`) | юрлицо, ИНН/ОГРН/КПП, регион, руководитель с должностью, дата прекращения | ~2 с |
| **Реестр МСП** (`rmsp.nalog.ru`) | категория (микро/малое/среднее), ОКВЭД с расшифровкой отрасли, город, лицензии, госконтракты | ~0,2 с |
| **«Работа России»** (`opendata.trudvsem.ru`) | активные вакансии сейчас, последняя, email работодателя | 5–60 с |

Защиты: ИНН/ОГРН принимаются **только по контрольной сумме** (иначе любое 10-значное число уходит в реестр как мусор), при поиске по названию выбирается точное совпадение и предпочитается действующая запись (в выдаче бывает до 20 однофамильцев, часть — ликвидированные).

Границы: в Telegram-объявлениях и на части бирж заказчик не называет ни ИНН, ни компанию — там обогащение отвечает «не найден». Лучше всего работает там, где он себя называет: сайты, HH, ЕИС, подписанные посты, входящая переписка.

## Схлопывание дублей

Один заказ часто висит одновременно на бирже, в RSS и в нескольких Telegram-каналах. Движок оставляет один лид, а в карточке сохраняет ссылки на остальные площадки — чтобы было видно, где ещё стоит откликнуться. Метрика «схлопнуто дублей» выводится в консоль и в отчёт.

## Правила с приоритетами

Плоский фильтр умеет только «выбросить» — и режет настоящие заказы вместе с шумом. Движок правил (`integrations/rules.py`) даёт три действия — **drop / penalty / boost** — и приоритет: **сильный сигнал покупки перебивает мягкий признак шума.** «Ищем подрядчика в команду, нужен бот, бюджет 80 тыс» — это заказ, а не вакансия, хотя слово «ищем» на месте. Четыре типа сопоставления: exact, contains, regex, fuzzy (ловит опечатки). Правила правятся в `rules.json` рядом с движком — без правки кода.

## История прогонов

Один и тот же заказ приходит из разных каналов неделю подряд. Отчёт помечает **🆕 новый** или **♻ сколько дней назад видели**, новые лиды поднимаются выше при равном скоре. Флаги `--no-history` и `--reset-history`.

## Проверенность

- Полный прогон 53 ниш: 4407 постов → 589 в нише → 🔥49 тёплых лидов за 35 секунд (быстрый режим).
- Бенчмарк на шести площадках разной природы с ручной разметкой 110 карточек: `BENCHMARK.md`, `EVAL.md`.
- Обогащение проверено на живых данных 24.10.2026: по одному ИНН — юрлицо, ФИО руководителя, регион, 107 активных вакансий и рабочий email; из поста в Telegram-канале — ООО с отраслью, годом регистрации и ФИО генерального директора.
- Самопроверки: `python integrations/sources.py --selftest` (правила скоринга), `python integrations/enrich.py --selftest` (контрольные суммы и разбор якорей).
